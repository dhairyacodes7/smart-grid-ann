Universal Multi-Voltage Transmission Line Fault Classifier Theory

1. Universal Feature Vector (13 Dimensions)

To enable a single neural network to operate across any grid voltage level (11kV to 765kV), the voltage level $V_{\text{level\_kV}}$ is supplied alongside normalized symmetrical components:

x = [ V_level_kV, Va_rms, Vb_rms, Vc_rms, Ia_rms, Ib_rms, Ic_rms, V0, V1, V2, I0, I1, I2 ]

2. Symmetrical Sequence Transformations

[ I0 ] 1 [ 1 1 1 ] [ Ia ] [ I1 ] = --- [ 1 a a^2 ] * [ Ib ] where a = e^(j 120°) [ I2 ] 3 [ 1 a^2 a ] [ Ic ]
